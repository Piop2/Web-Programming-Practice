> 과제 공지의 요구사항 정의서와 같은 형식으로 씁니다.

>

> **수용 기준 작성법**: "이 요구사항이 완료되었다"고 판단하는 기준입니다. 누가 확인해도 Pass / Fail이 같게 나오도록 씁니다.
