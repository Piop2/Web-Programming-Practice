## 피드백

현재 스타일(종이색 + 주황 포인트, 활동명 배지, 밑줄 GitHub 링크)은 유지하고 다듬을 부분만 정리.

- 소속·소개 간격을 4~6px로 통일한다.
- 배지는 텍스트 블록 전체 중앙이 아니라 활동명 첫 줄 기준으로 맞춘다.
- 헤더 상하 padding을 통일한다.
- 배지와 텍스트 사이 간격을 20~24px로 확대한다.
- 소속은 14~15px 및 `--heading`, 소개는 18px 및 `--text`로 정보 위계를 구분한다.
- `ACTIVITY` 라벨은 한글로 바꾸거나 제거한다.
- 활동명은 `<h1>`, 소속·소개는 `<p>`로 구성한다.
- GitHub 링크는 구체적인 텍스트와 `aria-label`을 제공하고, `target="_blank" rel="noopener noreferrer"`를 적용한다.
- 링크는 활동명 첫 줄 또는 헤더 기준으로 정렬하고 `:focus-visible` 및 hover 상태를 확인한다.
- 좁은 화면에서는 GitHub 링크를 텍스트 아래로 내리며 소개가 잘리지 않게 한다.
- 하단 구분선과 콘텐츠 정렬 기준을 확인하고, 1280px에서 스크롤 없이 표시되는지 검증한다.

## 반영 내용

- [index.html](../../index.html)의 `ACTIVITY` 라벨을 제거하고 활동명·소속·소개를 의미에 맞는 요소로 유지했다.
- GitHub 링크를 `GitHub 프로필 ↗`으로 구체화하고 `aria-label`, `noopener noreferrer`를 추가했다.
- [styles.css](../../styles.css)의 헤더를 `flex-start` 기준으로 정렬하고 배지-텍스트 간격을 24px로 조정했다.
- 소속을 15px/`--heading`, 소개를 18px/`--text`로 설정하고 두 요소의 간격을 4px·6px로 통일했다.
- 링크를 활동명 첫 줄 기준으로 정렬하고, 768px 이하에서 텍스트 아래로 줄바꿈하도록 보완했다.
- 기존 종이색·주황 포인트·밑줄 링크와 헤더 전체 너비 구분선은 유지했다.

## 후속 확인

- HTML 구조 및 링크 속성을 정적 검사했다.
- 1280px 기준 헤더 콘텐츠가 한 줄 레이아웃으로 유지되는지 확인했다.
- 좁은 화면에서 소개 문장이 잘리지 않고 GitHub 링크가 다음 줄로 배치되는지 확인했다.
