# 결과물 피드백

- 작성일: 2026-10-19
- 대상 결과물: 개인 이력서 웹페이지의 웹프로그래밍 주차별 링크
- 관련 작업: 예정 주차 표시와 반응형 스타일 정리
- 상태: 반영 완료

## 피드백

캐시 지우고 새로 고침해도 웹프 주차별링크 안에 섹션에 예정 부분만 내가 연하게 하라고 했잖아 근데 로컬에서는 잘 되는거 같은데 배포 링크 들어가면 적용이 안되는거 같아 is-planned 스타일 태그 말하는거임

그리고 안쪽에 예정 글씨는 지워줘

예정 글씨 없어져도 다른 것들이랑 몇 주차인지 글씨 위치 똑같이 해둘 것

반응형 관련된건 다 지우고

## 반영 내용

- [index.html](../../index.html)의 08~15주차 예정 블록에서 안쪽 `예정` 문구를 제거했다.
- [styles.css](../../styles.css)의 `.is-planned .week-label`에 연한 색상을 직접 지정해 배포 CSS에서도 예정 주차 글씨가 확실히 연하게 표시되도록 했다.
- [styles.css](../../styles.css)의 예정 블록에 빈 상태 문구 영역을 유지해 다른 주차 카드와 주차 숫자의 가로·세로 위치를 맞췄다.
- [styles.css](../../styles.css)에서 화면 너비별 `@media` 규칙과 그 안의 반응형 레이아웃 조정을 제거했다.

## 후속 확인

- 예정 주차의 숫자 위치와 실습·OT·휴강 주차 카드의 위치가 동일한지 확인한다.
- 고정 레이아웃에서 콘텐츠가 의도한 방식으로 표시되는지 확인한다.
