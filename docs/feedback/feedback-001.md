- 관련 작업: 실적 표의 정보 계층과 칩 태그 디자인 개선
- 상태: 반영 완료

## 피드백

Warm Editorial Resume 콘셉트에 맞춰 실적 섹션을 다음과 같이 구성한다.

- 표의 첫 번째 행인 `주요 실적 목록`은 표 밖의 섹션 제목 또는 설명으로 분리한다.
- 표에는 시기, 분류, 내용, 역할의 데이터 헤더와 데이터만 둔다.
- 분류는 `#fff0e9` 배경, `#eb5e28` 글자, `#f4c4ae` 테두리의 주황 강조 칩으로 표시한다.
- 역할은 투명 배경, `#403d39` 글자, `#ccc5b9` 테두리의 중립 칩으로 표시한다.
- 내용 열은 약 55%로 가장 넓게 배치하고 긴 문장을 줄이지 않는다.
- 내용은 `line-height: 1.7`로 읽기 편하게 표시하고, 모든 셀은 위쪽 정렬한다.
- 표는 최소 너비와 가로 스크롤을 제공해 모바일에서도 내용을 억지로 압축하지 않는다.
- 실적 행 안에는 카드나 그림자를 추가하지 않는다.

## 반영 내용

- [index.html](../../index.html)의 실적 섹션에서 표 caption은 스크린 리더용으로 유지하고, 화면에 보이는 `주요 실적 목록` 문구는 제거했다.
- [index.html](../../index.html)의 분류와 역할 텍스트를 `chip--category`, `chip--role` 요소로 변경했다.
- [styles.css](../../styles.css)에 칩, 표 열 비율, 내용 줄간격, 최소 너비와 가로 스크롤 스타일을 추가했다.
- 기존 실적 문장, 시기, 분류, 역할의 사실 내용은 변경하지 않았다.

추가 조정:

- 실적 옆 `01.` 번호를 제목과 같은 기존 크기로 되돌렸다.
- 표의 내용 열에만 적용되던 별도 글자색을 제거해 인접한 데이터와 같은 색으로 통일했다.

## 후속 확인

- 정적 검사 결과 외부 스타일시트 연결, 3개 section, 2개 실적 데이터 행,
  분류 칩 2개, 역할 칩 4개, 접근 가능한 caption, 인라인 style/script 부재를 확인했다.
- `styles.css`에서 내용 열 55%, `line-height: 1.7`, `min-width: 47.5rem`,
  `overflow-x: auto` 규칙을 확인해 모바일 가로 스크롤 조건을 검수했다.
