# 결과물 피드백

- 작성일: 2026-10-19
- 대상 결과물: 개인 이력서 웹페이지의 웹프로그래밍 주차별 링크
- 관련 작업: 예정·OT·휴강 주차 블록의 글씨 색상 구분
- 상태: 반영 완료

## 피드백

웹프로그래밍 주차별 링크에서 예정된 주차같은 비활성화 블록은
안쪽 글씨 색 연하게 해줘

## 반영 내용

- [styles.css](../../styles.css)의 비활성화 주차 블록인 예정·OT·휴강 상태에 더 밝은 보조 텍스트 색상(`#aaa49b`)을 적용했다.
- 첫 번째 색상 조정 후에도 차이가 잘 보이지 않는다는 추가 피드백을 반영해 색상을 한 단계 더 밝게 변경했다.
- 예정 주차(`is-planned`)만 연한 글씨를 사용하고, OT·휴강(`is-clossed`)은 기존의 잘 보이는 글씨 색상으로 되돌렸다.

## 후속 확인

- 활성 실습 링크와 OT·휴강 블록의 글씨 색상은 기존 스타일을 유지하고, 예정 주차만 더 연하게 표시되는지 확인한다.
