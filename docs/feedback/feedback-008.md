# 결과물 피드백

- 작성일: 2026-10-18
- 대상 결과물: 개인 이력서 웹페이지의 웹프로그래밍 주차별 링크 영역
- 관련 작업: OT·휴강 상태 클래스 통일 및 비활성 상태 스타일 적용 원인 분석
- 상태: 반영 완료

## 피드백

배포된 사이트에서 `is-ot`와 `is-closed` 스타일이 이상하다. 두 태그를 `is-clossed`로 통일하고 스타일이 적용되지 않는 이유를 분석한다.

## 반영 내용

- [index.html](../../index.html)의 OT·휴강 목록 항목 클래스명을 모두 `is-clossed`로 통일했다.
- [styles.css](../../styles.css)의 해당 선택자를 `is-clossed` 하나로 통일해 두 상태가 같은 실선 보더와 레이아웃을 사용하도록 했다.
- 배포된 `styles.css`를 확인한 결과 `.is-ot`와 `.is-closed` 선택자가 모두 없고 `.is-planned` 선택자만 존재했다. 배포 HTML에는 두 클래스가 남아 있었으므로, 저장소의 최신 CSS가 배포되지 않았거나 캐시된 이전 CSS가 제공된 것이 스타일 미적용 원인이다.

## 후속 확인

- 수정 후 `index.html`과 `styles.css`에 `is-ot`·`is-closed`가 남아 있지 않은지 정적 검색한다.
- 배포 후 브라우저에서 `/styles.css`가 `.week-list .is-clossed`를 포함하는지 확인하고, 01주·04주에 실선 보더와 카드 패딩이 적용되는지 확인한다.
