# 결과물 피드백

- 관련 작업: 수강 과목 카드의 내부 여백과 목록 밀도 조정
- 상태: 반영 완료

## 피드백

현재 섹션은 Warm Editorial Resume 콘셉트의 색상과 얇은 테두리, 오른쪽 이수 구분 칩을 일관되게 잘 사용하고 있다. 다만 카드의 세로 높이에 비해 실제 정보량은 6개 행뿐이어서 제목과 첫 번째 과목 사이 및 행 내부의 세로 여백이 다소 크게 느껴질 수 있다.

카드의 가로 폭과 바깥 여백은 유지하고, 카드 내부의 위아래 여백과 각 과목 행 높이만 조정한다. 카드 상단 패딩은 40px, 제목 아래 여백은 28px, 과목 행 패딩은 20px 0, 카드 하단 패딩은 32px로 맞춘다. 섹션 외부 여백은 72px 리듬을 유지한다.

전공과 교양은 같은 중립 칩을 사용하고, 주황색은 실제 상호작용이 있는 웹프로그래밍 과목 링크에 남겨 둔다. 작은 화면에서는 긴 과목명이 자연스럽게 줄바꿈되고 칩과 겹치지 않도록 flex 정렬을 유지한다.

## 반영 내용

- [index.html](../../index.html)의 수강 과목 섹션에 `courses` 클래스를 추가해 해당 카드에만 전용 내부 여백을 적용했다.
- [styles.css](../../styles.css)의 수강 과목 카드에 상단 40px, 좌우 44px, 하단 32px 패딩과 제목 아래 28px 간격을 적용했다.
- 과목 행 패딩을 20px 0으로 조정하고, 과목명 영역의 축소와 이수 구분 칩의 고정 폭을 설정했다.
- 이수 구분 칩은 중립색을 유지하면서 세로 패딩과 줄간격을 정리했다.
- 600px 이하에서 카드 패딩을 32px 20px 24px, 행 패딩을 16px 0으로 조정하고 긴 과목명과 칩이 겹치지 않도록 했다.

## 후속 확인

- 수강 과목 6개와 웹프로그래밍 과목의 F-05 앵커 링크는 변경하지 않았다.
- 실적 및 주차별 링크 섹션의 외부 여백과 기존 색상 체계는 유지했다.
