# 결과물 피드백

- 작성일: 2026-10-18
- 대상 결과물: 개인 이력서 웹페이지
- 관련 작업: Warm Editorial 이력서 디자인 적용
- 상태: 반영 완료

## 피드백

개인 이력서 페이지를 따뜻한 종이 위에 정리된 개발 기록처럼 보이는
Warm Editorial 스타일로 다시 작업한다.

- 페이지 전체 배경은 `#fffcf2`, 본문은 `#252422`, 제목은 `#403d39`,
  구분선은 `#ccc5b9`, 강조색은 `#eb5e28`을 사용한다.
- header, main, section, footer의 의미 구조와 지정된 순서를 유지한다.
- header에는 활동명 배지, 활동명, 소속, 한 줄 소개, GitHub 링크만 배치한다.
- 섹션 제목은 `01. 실적`, `02. 수강 과목`,
  `03. 웹프로그래밍 주차별 링크`처럼 번호를 붙인다.
- 실적은 최신순 table로 표시하고, 수강 과목은 목록으로 표시한다.
- 주차별 링크는 완료 주차와 예정 주차를 구분하며, 예정 주차에는 링크를 넣지 않는다.
- 콘텐츠 최대 너비는 1040px, 모바일 좌우 여백은 20px,
  데스크톱 좌우 여백은 32px, 섹션 간 여백은 72px 내외로 구성한다.
- 본문은 왼쪽 정렬하고, 과도한 주황색 배경과 진한 그림자는 사용하지 않는다.
- 모든 링크는 키보드 포커스가 가능해야 하며 `:focus-visible` 스타일을 제공한다.
- 실명, 학번, 사진, 이메일, 전화번호 등 금지된 개인정보는 사용하지 않는다.
- 확인되지 않은 실적이나 주차별 링크는 임의로 추가하지 않는다.

## 반영 내용

- [index.html](../../index.html)에 활동명 배지, 번호형 섹션 제목,
  의미 구조, GitHub 외부 링크 표시, 1~15주차 예정 상태를 반영했다.
- [styles.css](../../styles.css)에 Warm Editorial 색상 변수, 반응형 레이아웃,
  표·목록·주차 버튼 스타일, 키보드 포커스 스타일을 반영했다.
- 제공된 원본 자료에 없는 실적과 주차 링크는 추가하지 않았다.
- 정적 검사를 통해 15개 주차, 3개 section, GitHub 링크 1개,
  인라인 스타일 없음, 날짜 형식을 확인했다.

## 후속 확인

- 실제 주차별 실습 페이지가 생성되면 해당 주차에만 링크를 추가한다.
- 실적 자료가 추가되면 기존 최신순 정렬을 유지한다.
- 배포 저장소의 실제 마지막 커밋 날짜를 확인한 뒤 footer 날짜를 갱신한다.
