# 결과물 피드백

- 작성일: 2026-10-18
- 대상 결과물: 개인 이력서 웹페이지의 웹프로그래밍 주차별 링크 섹션
- 관련 작업: 주차 상태 구분 및 링크 목록 밀도 개선
- 상태: 반영 완료

## 피드백

15개 주차가 모두 예정으로 표시되어 진행/예정 상태를 구분할 수 없으므로, 최소 1~2주차는 진행 상태로 표시한다. 주차 카드는 높이와 숫자-상태 간격을 줄이고, 진행 주차와 예정 주차를 색과 텍스트로 구분한다. 주차 목록은 의미 있는 목록 요소로 구성하며 진행 주차만 링크와 키보드 포커스를 제공한다. 바깥 섹션의 이중 테두리와 하단의 과도한 여백을 정리하고, 데스크톱 5열·태블릿 3열·모바일 2열로 반응형 배치한다.

## 반영 내용

- [index.html](../../index.html)의 1주차만 링크로, 2~15주차를 링크 없는 `is-planned` 목록 항목으로 변경했다.
- 진행 주차에는 `실습 보기 →`, 예정 주차에는 `예정` 텍스트를 넣어 색상 외 상태 단서를 추가했다.
- [styles.css](../../styles.css)의 주차 목록을 자동 채움 그리드로 변경하고 카드 높이, 내부 여백, 숫자-상태 간격을 축소했다.
- 진행 주차는 `--heading` 배경과 `--paper` 글자, hover 시 `--accent`를 사용하고 예정 주차는 투명 배경과 점선 테두리를 사용하도록 구분했다.
- 주차 섹션의 불필요한 내부 중첩을 정리하고, 진행 링크의 `:focus-visible` 스타일을 유지했다.
- 후속 확인을 위해 03 섹션의 바깥 테두리를 복원하고 활성/예정 항목에 동일한 최소 높이와 내부 여백을 적용했다.

## 후속 확인

- 1~15주차가 모두 표시되고 1주차만 Tab 키로 포커스되는지 확인했다.
- 진행 주차는 링크로 이동하고 예정 주차는 링크가 없는지 확인했다.
- 실제 배포 환경에서 1주차 실습 페이지 경로가 제공되면 현재 링크를 해당 실습 페이지 상대 경로로 교체해야 한다.
